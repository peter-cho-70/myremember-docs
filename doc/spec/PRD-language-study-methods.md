# PRD — 외국어 "나에게 맞는 공부법 + 복습 스케줄러" (초안)

작성: 2026-11-01 · 상태: **1~3단계 구현 완료 (2026-11-01)** · 위치: 외국어 듣기 위에 새 메뉴 "공부법"

## 1. 목적

지금의 외국어 듣기는 "그날 자료를 듣는" 기능이다. 빠진 것은 두 가지다.
1. **잊어버리기 전에 다시 꺼내 보게 하는 장치** (특히 50대 이상의 "자주 까먹음").
2. **사람(나이·목적)마다 다른 공부 방식 안내** — 본인, 가족, 강의 수강생 등 여러 프로필.

## 2. 조사 요약 (2026-11-01 기준 웹 검색)

| 내용 | 설계 반영 | 근거 신뢰도 |
|---|---|---|
| 간격 반복(spaced retrieval)은 노년층에도 효과가 있고, 연령 간 효과 차이는 작다 ([Simone 2012](https://www.Gwern.net/doc/psychology/spaced-repetition/2012-simone.pdf), [PMC4480221](https://pmc.ncbi.nlm.nih.gov/articles/PMC4480221)) | 모든 프로필에 간격 복습 적용 | 연구 있음 (단어목록·얼굴-이름 과제, 어학 수업 아님) |
| 노년층은 복습 사이에 다른 항목이 2개만 끼어도 급격히 잊고, 젊은층은 5개까지 버틴다 ([Maddox 2011, 요약](https://www.science.gov/topicpages/e/equal+spaced+retrieval)) | 50대+ 프리셋은 **한 번에 적은 수·짧은 세션·같은 날 재확인** | 연구 있음 (요약만 확인) |
| 의미 기억(어휘)은 유지되지만 **이미 배운 것을 꺼내는 인출**이 약해진다 ([Frontiers 2022](https://www.frontiersin.org/articles/10.3389/fnhum.2022.787413/full) 등) | 복습은 "다시 읽기"보다 **떠올려 보기 → 정답 확인**, 힌트 단계 제공 | 중간 |
| 새 단어와 뜻을 **연결(결합)** 하는 능력이 약해진다 | 단어마다 예문·소리·내 경험 연결 메모 유도 | 중간 |
| 2024 학위논문: 노년층은 인출 연습과 단순 반복 학습의 효과가 비슷했고 젊은층은 인출 연습이 더 유리 ([WUSTL](https://openscholarship.wustl.edu/art_sci_etds/3015)) | 50대+는 인출 위주로 강제하지 않고 **듣기·따라 읽기와 번갈아** 구성 | 낮음 (학위논문 1건, 제목만 확인) |
| 확장 간격이 장기 기억에 더 낫다는 근거는 엇갈림 ([PubMed 18421627](https://pubmed.ncbi.nlm.nih.gov/18421627)) | 간격은 고정 공식 대신 **내 정답 여부로 조정** | 엇갈림 |
| 유행: AI 대화 연습, 실제 대화에서 카드 만들기, 적응형 간격(FSRS) ([ISSEN 2026-06](https://issen.com/blog/most-effective-language-learning-techniques-ai), [Kaiwa](https://trykaiwa.com/blog/best-ai-language-learning-apps-2026)) | 회화 연습의 문장을 복습 카드로 보내기, FSRS 유사 간격 | **업체 블로그 위주 — 효과 근거 아님, 유행 참고용** |
| 섀도잉은 발음 코칭 맥락에서 언급되나 독립 근거는 얇음 | "따라 읽기" 단계는 선택 항목으로만 | 낮음 |

**확인 못 한 것:** 노년 L2 학습자의 오류 없는 학습(errorless learning) 연구, 확장/균등 간격의 직접 비교. 이 부분은 단정하지 않는다.
**주의:** 아래 프리셋 숫자는 위 연구의 직접 수치가 아니라 **출발값(가정)** 이며, 쓰면서 조정하도록 설계한다.

## 3. 기능 범위

### A. 프로필
- 이름, 연령대(20·30대 / 40대 / 50대+ / 직접), 목표(여행·회화·강의·시험), 하루 가능 시간.
- 여러 프로필(본인·가족·수강생) 생성/전환. 복습 기록은 프로필별로 따로.
- 연령대는 **추천 출발값**일 뿐, 복습 간격·분량은 프로필에서 직접 수정 가능.

### B. 공부법 추천 화면
- 프로필을 고르면 "이 방식으로 해 보세요" 카드 3~4개 + 한 줄 근거(위 표) + 오늘의 루틴(예: 듣기 5분 → 떠올리기 5분 → 따라 읽기 3분).
- 근거 옆에 **신뢰도 표시**(연구 / 업체 글 / 가정)와 출처 링크, 기준일.

### C. 복습 스케줄러
- 소스: 외국어 듣기의 단어·예문, 회화 연습 문장. 항목마다 "복습에 담기" 버튼(또는 오늘 자료 전체 담기).
- 오늘 복습 목록: 소리를 먼저 들려주고 → 떠올리기 → 정답 확인 → 「기억남 / 가물가물 / 몰랐음」 3단계 평가.
- 다음 복습일: 평가에 따라 간격 늘림/유지/초기화. 프리셋별 출발값(가정):

| 프리셋 | 새 항목/일 | 첫 간격 | 확장 | 세션 길이 | 특징 |
|---|---|---|---|---|---|
| 20·30대 | 10~15 | 1일 | ×2.5 | 15분 | 인출 위주 |
| 40대 | 8~10 | 1일 | ×2.2 | 12분 | 인출+듣기 |
| 50대+ | 4~6 | 같은 날 재확인 → 1일 | ×1.8 | 8~10분 | 힌트 단계, 듣기·따라 읽기와 교차, "가물가물"은 짧은 간격으로 |

- 그날 못 하면 밀린 항목을 몰아서 보여 주지 않고, 분량 상한 안에서 오래된 것부터.

### D. 기록 보기
- 프로필별 연속 일수, 기억남 비율, 자주 틀리는 항목. (과한 게임화는 하지 않음)

## 4. 데이터·보안 (로컬 우선)
- 저장: `private/language-study/` (프로필 `profiles.json`, 복습 기록 `reviews-<프로필>.json`). git·클라우드 배포 제외.
- 이름 등 개인정보는 외부로 보내지 않음. 공부법 설명은 정적 텍스트(검색 결과를 요약해 코드에 포함), 실행 중 외부 호출 없음.
- 서버(`server.py`)에 `/api/study-*` 추가, 화면은 `study.html` + `study.js`, 메뉴는 외국어 듣기 위.

## 5. 단계별 구현 (제안)
1. **1단계 — 프로필 + 공부법 추천 화면** (정적 근거 카드, 가장 빠름)
2. **2단계 — 복습 스케줄러** (담기·오늘 목록·3단계 평가·간격 계산)
3. **3단계 — 기록 보기, 회화 연습 문장 담기, 프리셋 미세 조정**

## 6. 열린 질문
1. 복습 카드의 "정답 확인"에서 한국어 뜻을 먼저 보일지, 소리를 먼저 들려줄지 (듣기 앱이므로 소리 먼저를 제안).
2. 프로필 정보를 이 Mac 서버에만 둘지(제안), 수강생과 공유할 필요가 있는지(공유하려면 별도 설계).
3. 간격 알고리즘: 단순 규칙(제안) vs FSRS 계열 (구현 복잡도 큼).
